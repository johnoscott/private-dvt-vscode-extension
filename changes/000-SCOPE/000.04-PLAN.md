# Implementation Plan

## Approach: dbt-first, ref()-driven

The simplest useful graph comes from:
1. Read `dbt_project.yml` → get project name, model-paths
2. Walk model-paths for `.sql` files → each file = one model node
3. Regex-search each file for `{{ ref('...') }}` and `{{ source('...', '...') }}` → edges
4. Build a `DirectedGraph` from that → our own lightweight "manifest"
5. Visualize it

No SQL parsing needed for the initial graph. No manifest.json needed. No Python needed.
The `{{ ref() }}` pattern is the entire contract for dbt lineage.
